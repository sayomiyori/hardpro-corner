# Каталог в браузере

Open WebUI 0.13.4 показывает менеджеру данные архивной выгрузки 1С. Flowise 3.1.4 и официальный Flowise Embed 3.1.6 обслуживают покупателя. Оба используют существующий vLLM на одной RTX 3090. Модель получает вопрос и условия предыдущего поиска. Количество подставляет приложение.

## Источник для каждой роли

| Клиент | Где берутся сведения |
| --- | --- |
| Менеджер | Полная выгрузка на 18 ноября 2026 года, 12:05 МСК. При одинаковых характеристиках доступны номера строк. Пропущенная строка склада означает неизвестное количество. |
| Покупатель | При каждом вопросе витрина пересчитывает доступное количество через тот же метод, что карточка товара. Он учитывает активность варианта, резервы с действующим сроком и отправленные заказы. Приложение проверяет публикацию и видимость карточки. |
| Прямое чтение из 1С в будущем | Существующие импортёр, поиск по архиву и команда `hp-manager --onec` сохранены. |

Клиентский запрос проходит через `shop_relay.py`. Шлюз выбирает локальную или тестовую БД по разрешённому адресу витрины. Внутренний маршрут магазина выполняет чтение под его проверенным профилем, возвращает названия, артикулы, варианты и доступное количество. Исходящие запросы ограничены заранее заданными адресами. Между сервером и рабочим компьютером работают SSH-туннели. Временная выборка на запрос удаляется после ответа. Flowise хранит историю беседы в своей локальной БД. При недоступной витрине чат сообщает об ошибке.

## Запуск и проверка

1. Для Ubuntu установлены пользовательские службы `hardpro-openwebui`, `hardpro-flowise`, `hardpro-catalog` и `hardpro-widget`. Посмотреть их состояние можно через `systemctl --user status`.
2. Open WebUI работает в личном однопользовательском режиме. Браузер открывает его через SSH на порту 8765 рабочего компьютера. Редактор Flowise и vLLM остаются на loopback сервера.
3. На Windows запустите личный `open-catalog.cmd` из каталога подключения к стенду. Он поднимает туннель, локальную витрину и передачу запросов тестового домена. Для тестового домена нужен действующий пароль витрины. Удалённый виджет зависит от доступности рабочего компьютера и GPU-сервера.
4. На странице каталога откройте «Чат по товарам». Сначала укажите только название, второй репликой уточните цвет и размер, третьей смените город. Сверьте оба числа по одному SKU с данными карточки. Вопрос «Сколько всего товаров на сайте?» показывает количество опубликованных карточек и активных вариантов.
5. Проверка 19 ноября 2026 года охватила Open WebUI и оба экземпляра магазина. Сравнивались уточнение варианта, свободное количество и смена города в реальном Chrome. Заказы, резервирование и изменения остатков для проверки не требуются.

Проекция архива `project_customer.py` пригодна для отдельной архивной проверки. Рабочий виджет запрашивает базу сайта на каждой реплике.
