# Проверка менеджерского чата HARD-PRO

Проверка 25 ноября 2026 года. Менеджерский чат в Open WebUI использует каталог для проверяемых сведений о товарах. Покупательский чат читает опубликованные данные витрины.

## Диалог и поиск товаров

В первом прогоне из 69 реплик Open WebUI были успешны 47, частично успешны 10, неуспешны 12. При повторной проверке отклонений в рабочем API прошли 25 из 25 сценариев. Ещё 10 запросов проверили через интерфейс Open WebUI.

При смене города менеджер сохраняет модель, при смене веса — город и цвет. Категория остаётся обязательным условием поиска, даже если совпал бренд. Цены и количества берутся из товарных записей.

## Сводки продаж и закупок

Сводки доступны во внутреннем менеджерском режиме. Общие итоги подбираются за указанный период. Запрос по товару или магазину требует отдельного среза. Суммы оборота берутся из проверенного источника и доступны по правам роли.

## Статус заказа

В менеджерском режиме поиск использует точный номер, который указал сотрудник. Пока номер отсутствует, бот запрашивает его. Покупательский виджет направляет вопросы о конкретном заказе к сотруднику магазина.
