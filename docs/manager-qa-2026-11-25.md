# Проверка и дообучение менеджера 25 ноября 2026 года

После прогона 69 вопросов исправили рабочую выдачу каталога и подключили закрытый
снимок данных 1С. Изначальный прогон Open WebUI дал 47 успешных, 10 частичных
и 12 неуспешных сценариев. Повторная проверка направлена на найденные ошибки.

## Рабочий чат

| Сценарий | Что проверили |
| --- | --- |
| Связь с «Розницей» | Разговорный вопрос о рабочей базе после товарного подбора запускает пробное чтение. В ответе видны результат и время. |
| Цена и наличие | Подбор по бюджету учитывает остаток в любом подходящем магазине. Явный запрос обоих магазинов требует положительного остатка в каждом. |
| Варианты и уточнения | Номер из списка открывает выбранный товар. Номер другой позиции возвращает к товарному списку. При смене города сохраняется модель, а при смене веса сохраняется город. |
| Поиск категории | Запросы рашгардов и тайских носков сохраняют категорию вместе с брендом. Длинная выдача по модели начинается с вариантов с подтверждённым остатком. |
| Разные источники цен | Запрос цены сайта сообщает статус витрины. Розничная цена 1С выводится под отдельным обозначением. |
| Сводки | Объём продаж по отдельному товару или магазину требует отдельного среза. Общая сводка доступна по явному запросу общих итогов за период. |
| Консультации | Ответы об унциях, обуви и боксерских перчатках учитывают справку по экипировке. |

В рабочем API прошли 25 из 25 регрессионных сценариев, на сервере прошёл 41
автотест. В Open WebUI отправили 10 запросов через интерфейс временного чата.
Отдельно проверили первый подбор после перезапуска каталога с закрытым снимком.
По рабочему API подбор кап BoyBo списком занял 1,63 с. В исходном браузерном прогоне
холодный поиск с загрузкой всего справочника занял 31,96 с. Эти два результата
измерены на разных уровнях, поэтому характеризуют задержку холодного поиска
в соответствующих условиях.

## Сверка через MCP 1С

В каталоге 4 587 товаров, 21 015 привязанных характеристик и 1 481 строка
без характеристики. Сверили по MCP все коды и наименования товаров и количество
характеристик у действующей номенклатуры. У 3 078 товаров заполнено описание,
у 1 821 заполнен производитель. У 1 804 товаров подтверждена розничная цена
для текущих вариантов. Всего подтверждено 7 598 таких цен. Ценовые строки
с другими характеристиками сохранены отдельно и не назначаются текущим
вариантам по одному совпадению наименований.

Независимый контроль через MCP и Open WebUI дал одинаковые цену и свободный
остаток для выбранной характеристики капы BoyBo Basic. При обновлении снимка
действующий чат продолжает читать свежие розничные цены и остатки из 1С.
[Как обновить снимок и повторить приёмку](manager-data-access.md)

## LoRA на Qwen3-14B-AWQ

Провели два прогона с замороженными рабочими весами AWQ. Веса распаковывались
на GPU для линейных операций, оптимизатор обновлял только LoRA rank 8 на
проекциях Q и V. В итоговом прогоне 67 синтетических обучающих примеров
по диалогу, товарному поиску и маршрутизации запросов. Номера заказов вымышлены.
Реальные остатки, розничные цены и суммы оборота берутся только из источника.

| Итоговый прогон, 29 отложенных примеров | Правильный разбор | JSON по схеме |
| --- | ---: | ---: |
| Те же AWQ-веса без адаптера, локальная генерация | 15/29 | 16/29 |
| AWQ и обученный адаптер, локальная генерация | 27/29 | 29/29 |
| Рабочая AWQ через vLLM с ограничением JSON | 24/29 | 29/29 |

Для отчётов оценивали действие и точные поля, в том числе даты и номер заказа.
Для обычного диалога таблица учитывает выбор действия и непустой текст.
Ручная оценка показала ошибки адаптера в назначении капы и устройстве обуви.
Рабочий чат использует базовую Qwen3-14B-AWQ со справкой по экипировке.

Для воспроизведения используйте окружение vLLM с Transformers, Torch и CUDA.
Путь для результата должен отсутствовать до запуска. Скрипт сохраняет адаптер,
метрики и синтетические ответы рядом. Пиковый резерв CUDA в итоговом прогоне
составил 10,68 ГиБ. Модель кодинга после прогона запущена и проверена.

```bash
PYTHONPATH=manager-demo/web:manager-demo python -B \
  manager-demo/training/train_manager_awq.py /path/to/Qwen3-14B-AWQ /path/to/adapter-output
```
