# Чат-модели и работа с документами

Обновлено 21 ноября 2026 года. Отчёт описывает настройку речевых и текстовых моделей Open WebUI на сервере локальных моделей. Все значения окружения с реальными ключами хранятся вне Git в файлах на сервере.

## Роутер llama.cpp

Сервер чат-моделей работает в режиме роутера с пресетом из трёх моделей: `Qwen3.8-Flash-Next`, `Qwen3.8-27B-UD-Q5_K_M` и `Huihui-Qwen3.8-27B-abliterated-Q5_K`. Параметр `--models-max 1` держит в памяти одну модель; запрос к другой автоматически выгружает текущую и загружает нужную. Пресет задаёт только пути к весам, общие параметры вынесены в drop-in системного юнита: контекст 262 144 на два слота, tensor override для CPU-выгрузки экспертов Flash-Next, обе RTX 3090.

Замер переключения моделей контрольной генерацией по очереди:

| Модель | Время ответа со сменой модели |
| --- | --- |
| Qwen3.8-Flash-Next | 12,5 с |
| Qwen3.8-27B-UD-Q5_K_M | 7,2 с |
| Huihui-Qwen3.8-27B-abliterated-Q5_K | 5,5 с |
| возврат на Qwen3.8-Flash-Next | 12,9 с |

Ограничения: первый токен после смены модели занимает от 15 секунд (27B) до 90 секунд (Flash-Next читает 93 GB с NVMe); после 5 минут простоя модель выгружается (`--sleep-idle-seconds 300`). При росте нагрузки стоит увеличить паузу выгрузки или собрать две модели в память на двух картах.

## Документы (RAG)

Загрузка документов падала на шаге векторизации: в offline-режиме Open WebUI требует полный снапшот эмбеддинговой модели в кэше, частичная загрузка приводила к молчаливому отсутствию модели. Решение: полный снапшот `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (28 файлов) в локальный кэш на модельном NVMe, `HF_HOME` и `RAG_EMBEDDING_MODEL` в окружении служб. Выбрана мультиязычная модель, потому что каталог и запросы менеджеров на русском; префиксы запросов не требуются.

Проверка: файл загружен через API администратора, обработка завершилась со статусом completed; контрольный поиск по векторному хранилищу вернул нужный фрагмент с расстоянием 0,22. У модели `Qwen3.8 Flash Next` включено свойство загрузки файлов, потому что оно было отключено в настройках чата. Файлы, загруженные до включения векторов, нужно перезалить.

## Изображения, видео и голос

`Qwen3.8-Flash-Next` — текстовая модель, проектора для неё нет. Изображения и видео обрабатывает отдельная 27B-модель с mmproj-проектором («HARD-PRO Медиа»). Рантайм llama.cpp поддерживает приём видео (`video_url`), для декодирования установлен статический ffmpeg и ffprobe без прав администратора в пользовательский каталог; путь добавлен в окружение юнита мультимодальной модели.

Проверено запросами к API: изображение PNG — модель ответила по содержимому; тестовый ролик MP4 2 секунды — модель описала содержимое; контрольный WAV — эндпоинт транскрипции вернул статус 200. Голосовой ввод работает на faster-whisper с локальной моделью whisper-small; озвучка ответов — браузерный синтез на стороне клиента.
