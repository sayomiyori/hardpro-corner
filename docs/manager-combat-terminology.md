# Словарь экипировки для помощника HARD-PRO

20 ноября 2026 года сопоставили названия из каталога с регламентами, перечнями экипировки федераций, справочниками производителей и русскоязычными примерами употребления. Первая версия содержала 166 карточек, 842 поисковых написания, 30 разделов по дисциплинам и три общих раздела. В записях сохраняются ссылки на источники, значение и условия подбора.

25 ноября расширили словарь до 170 карточек, 917 вариантов написания и 68 источников. В рабочем чате проверены разговорные обозначения массы, уточнения без повторения товара и поиск по сленгу. [Текущий словарь](../manager-demo/web/combat-terminology.json) · [Проверка на 50 вопросах](manager-equipment-slang.md)

Например, региональная федерация бокса использует «снарядки» и «блинчики», «шингарды» встречаются в русскоязычных каталогах защиты, а «каратэги» используют производители. ## Работа помощника

Точные дополнения к запросу сохраняются. Например, «тай‑пэды до 8000» ведут к тайским лапам с сохранением бюджета. «Хогу» означает жилет для тхэквондо, а «кудоги 160» ведут к форме кудо с ростом 160. Дефис внутри артикула защищает его от подстановок. По запросам «блинчики», «ФКР», «ги» и «щитки» проверяется контекст. Если он не разрешает значение, помощник задаёт короткий вопрос. По вопросам «что такое» и «расшифруй» он ищет определение и показывает ссылку.

Цены и остатки остаются результатом чтения 1С. Для подбора под соревнования нужны организация, дисциплина, возрастная категория, модель и положение турнира. Словарь содержит разделы для видов спорта, где источники удалось верифицировать. Дальнейшие жаргонные формы можно добавлять по реальным обезличенным вопросам менеджеров.

## Подготовка к загрузке в Qdrant

[Экспортёр](../knowledge-pilot/export_terminology.py) из того же источника делает четыре PDF с извлекаемым текстом и кликабельными ссылками, а также `hardpro-terminology-qdrant.jsonl`. В JSONL один объект на строку. Внешний `id` представляет стабильный UUID для повторных загрузок. В `payload` находятся короткий ключ, `scope` для фильтра по дисциплине, `kind`, `title`, `text`, `aliases`, `source`, `source_urls`, язык и дата сверки. Тематические фрагменты, карточки, спорные слова и заметки по регламенту можно индексировать по раздельным фильтрам.

При загрузке используйте `title` и `text` для построения эмбеддингов. Перед `upsert` добавьте вектор в соответствии со схемой выбранной коллекции. Для локальной проверки подходит [существующий гибридный пилот](knowledge-retrieval-pilot.md) с многоязычной MiniLM и BM25. PDF можно использовать в конвейере, где есть парсер документов. JSONL сохраняет готовые границы фрагментов и метаданные. [Формат точек Qdrant](https://qdrant.tech/documentation/manage-data/points/) · [Фильтры и поля payload](https://qdrant.tech/documentation/concepts/payload/)

В локальную коллекцию Qdrant в памяти загрузили 224 фрагмента. На 19 контрольных запросах гибридный поиск вернул целевой фрагмент среди первых трёх результатов с фильтром по дисциплине и без фильтра. Вопросы отобраны по содержимому этого словаря. Работу с продажами и качество на незнакомых формулировках оценивают отдельно. Из четырёх PDF извлечён текст всех 41 страниц. Ссылки на источники доступны в документах.

Воспроизведение экспорта на Windows из корня репозитория, в Python с ReportLab.

```powershell
python -X utf8 knowledge-pilot/export_terminology.py E:/Work/Temp/hardpro-terminology-export `
  --regular-font C:/Windows/Fonts/arial.ttf --bold-font C:/Windows/Fonts/arialbd.ttf
```
