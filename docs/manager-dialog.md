# Поиск и ответы менеджерского помощника

20 ноября 2026 года воспроизвели продолжение старой подборки при смене товара. В истории после вопроса о рашгардах разбор мог оставить прежний товар. Поиск также различал формы «капа» и «капы». Список из нескольких карточек формировался до чтения свободных остатков.

## Что изменилось

- Явная категория запускает поиск заново. Запрос «а в Симферополе?» уточняет город текущей подборки или выбранной модели. При запросе боксерских шлемов прежний бренд сбрасывается, а явное исключение бренда сохраняется при продолжении.
- Простые запросы про рашгарды, капы, бинты и шлемы разбираются приложением. Поиск учитывает формы слов, известные бренды из проверенного диалога и явные характеристики. Для более сложных запросов работает существующий разбор моделью. Отдельные рашгарды и комплекты различаются по названию карточки.
- При запросе «в наличии» приложение пакетно проверяет свободные остатки по первым 24 подобранным моделям. Показывает подтверждённые варианты и магазины. Если проверена часть каталога или сведения о части остатков отсутствуют, ответ сообщает об этом. При повторном разборе истории выполняется чтение только для текущей реплики.
- Подборка начинается с короткого ответа по запросу. При вопросе о пригодности шлемов для тхэквондо бот уточняет направление и цель. Если указано соревнование, приводит документ выбранной федерации и просит конкретную модель и положение старта. Это отправная точка для сверки, допуск артикула требует отдельного подтверждения. ## Проверка и результаты

В локальной ветке на Windows, Python 3.14 проверили все 12 реплик из сообщения пользователя на вымышленных товарах. Прошли также уточнение города для конкретной модели, обработка отсутствующих строк и сбоя читателя, ограничение размера пакета и выбор документа федерации. Для рабочих данных в тестах используются подставные ответы читателя.

Из 1С на чтение проверили по три карточки из четырёх категорий. Производитель заполнен у 5 из 12, у 11 из 12 вид номенклатуры общий, у 11 есть характеристики. Это точечная выборка. Перед переходом на фильтры по справочникам нужно проверить заполненность на расширенной выборке. Текущий код использует признаки из названий и характеристики.

Следующий шаг — пройти тот же диалог в Open WebUI на стенде и сверить наличие с 1С. Для вопросов о конкретном допуске пригодится отдельный пилот гибридного поиска и регламенты организаторов.
