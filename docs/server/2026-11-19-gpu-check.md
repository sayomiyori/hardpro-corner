# Проверка двух RTX 3090 · 19 ноября 2026 года

Обе карты прошли короткий тест CUDA с проверкой результата вычислений. Каждую карту нагружали по отдельности примерно одну минуту, затем обе одновременно ещё минуту. На 25-й минуте после загрузки обе карты отвечали. За окно наблюдения ошибка Xid 79 на ASUS не повторилась. На двух проверенных портах PCIe счётчики ошибок были нулевыми.

| Измерение | ASUS RTX 3090 | Palit RTX 3090 |
| --- | ---: | ---: |
| Линии PCIe под нагрузкой | 4.0 ×16 | 4.0 ×16 |
| ОЗУ → VRAM, одна карта | 26,09 ГБ/с | 26,08 ГБ/с |
| VRAM → ОЗУ, одна карта | 26,71 ГБ/с | 26,76 ГБ/с |
| Максимум температуры ядра при совместной нагрузке | 77 °C | 67 °C |

При совместном копировании суммарная пропускная способность составила 36,47 ГБ/с из ОЗУ в VRAM и 32,06 ГБ/с обратно. Прямой CUDA-доступ между картами недоступен в проверенной конфигурации. Копирование через ОЗУ дало 13,1–13,3 ГБ/с.

Драйвер не зафиксировал температурного троттлинга. Периодически срабатывало ограничение по мощности. Два тестовых запроса Ollama завершились успешно. Тестовая Qwen3 0.6B целиком загрузилась на ASUS.

Длительный нагрев остаётся открытым. Температура видеопамяти в этом прогоне недоступна через nvidia-smi. Скорость рабочей модели помощника пока не замерялась.
