# База знаний помощника менеджеров

20 ноября 2026 года собран первый набор терминов, вариантов написания брендов и правил соревнований. В проверочной версии помощник извлекает запись из [базы знаний](../manager-demo/web/manager-knowledge.json) по терминам запроса. Словарь помогает Qwen разобрать вопрос. Остатки, розничные цены, описания и характеристики берутся из 1С по ссылкам товара и характеристики.

Расширенный словарь по дисциплинам и состав комплекта для Qdrant описаны в [исследовании терминологии](manager-combat-terminology.md).

## Сленг и входные запросы

- «Снарядки до 5к» означает снарядные перчатки с розничной ценой 1С до 5 000 ₽ включительно. По умолчанию у варианта должен быть положительный свободный остаток в Севастополе и Симферополе. При запросе конкретного города проверяется этот город.
- «Покажи количество этих трёх» использует предыдущий список вариантов одной модели. Помощник показывает остатки после вычета резерва 1С по каждой характеристике. Ноль, отрицательный расчётный остаток и отсутствующая строка имеют разные подписи.
- «Блинчики» в контексте бокса и мешков означает снарядные перчатки. Контекст штанги означает диски. При коротком запросе помощник уточняет товар.
- «Перчи», «раш», «самбовка», «дзюдоги», «шингарды», «файтшортс» и транслитерации брендов сверяются с реальными категориями и названиями. Общие слова «кимоно», «защита» и «форма» могут потребовать уточнения вида спорта.

Источники словаря — категории и марки магазина, а также терминология Федерации бокса Республики Крым. Некоторые разговорные формы и варианты транслитерации добавлены для поиска. Их можно расширять на основе реальных обезличенных вопросов сотрудников. ## Правила соревнований

Поиск по федерации и дисциплине возвращает выдержку с названием источника и датой сверки. Общий запрос про тхэквондо требует уточнить WT или ИТФ. По самбо отдельно рассматриваются спортивная и боевая дисциплины. Для проверки артикула нужны положение конкретного турнира, возрастная группа, наличие маркировки и подтверждение включения модели в применимый перечень. В базе есть ссылки на категорию магазина для первичного подбора. [Документы Федерации бокса России](https://rusboxing.ru/olympic-boxing/documents) · [Правила самбо ВФС](https://sambo.ru/wp-content/uploads/2026/10/pravila-vida-sporta-sambo-s-izm.-i-dopolneniyami.pdf) · [Правила ИТФ 2026](https://itf-russia.ru/wp-content/uploads/2026/07/itf-tournament-rules-2026-russian.pdf) · [IBJJF о форме Gi и No-Gi](https://ibjjf.com/uniform)

## Чтение рабочих данных

Читатель Windows принимает только параметры фиксированных запросов по TLS с клиентским сертификатом. Два новых маршрута читают карточку по UUID и остатки с розничными ценами по группе до 24 товаров. Суммы проверяются при приведении к рублям и копейкам. Цены и остатки сопоставляются по паре UUID. Запросы к рабочей базе ограничены двумя настроенными физическими складами и типом цены «Розничная».

В рабочей 1С нужно проверить именно доступ учётной записи помощника к регистру цен. При ошибке чтения цен он сообщает, что подбор по бюджету недоступен. Запрос «цены на сайте» получает отметку о недоступности этого источника до подключения подтверждённого сопоставления с рабочей витриной.

В изолированной проверочной версии на Ubuntu прошёл сценарий с тремя цветами перчаток и свежими остатками обоих магазинов. В ограниченном прогоне запроса «снарядки до 5к» использованы цены, прочитанные из рабочей 1С через MCP, и свежие остатки из действующего читателя. Для трёх проверенных моделей найдено три подходящих варианта. Пять из шести ценовых строк совпали с действующими характеристиками по UUID. Шестая строка исключена. Отдельный запрос подтвердил, что 1С возвращает описание карточки. Для рабочей приёмки нужны проверка двух новых маршрутов под учётной записью помощника на Hoster и проход из Open WebUI.
