# HARD-PRO Hub

Доска локальных моделей, агент с инструментами, шлюз к Open WebUI и прокси для сбора метрик. Этот каталог появился после [ранней версии LAN Hub](../lan-hub/README.md).

[К репозиторию](../README.md) · [Статус стенда](../STATUS.md) · [Службы systemd](../systemd/README.md)

## Компоненты

| Путь | Назначение |
| --- | --- |
| `hub/` | Доска с состоянием моделей, использованием GPU, тестовыми прогонами и историей замеров |
| `agent/` | Чат с сессиями, инструментами и MCP. Публикует OpenAI-совместимую модель `hardpro-agent` |
| `gateway/` | LAN-вход на `8775`. `/hub/` ведёт на доску, `/agent/` к агенту, `/` в Open WebUI |
| `traceproxy/` | Агрегирует модели и добавляет к ответу метрики там, где они доступны. Типовой порт `9090` на loopback |
| `models/` | Реестр моделей и ролей, локальные запуски llama.cpp/vLLM и проверка внешних сервисов |
| `openwebui/` | Фильтр метрик для Open WebUI |
| `migrate/` | Перенос выбранных материалов Codex в локальное рабочее пространство |

## Установка на подготовленном Ubuntu

Установщик создаёт `~/hardpro`, окружение Python, ключи для TLS и пользовательские службы. Open WebUI, веса моделей и источники данных подготовьте отдельно. Установщик направляет веб-чат на loopback-порт `8765`. Если у Open WebUI другой порт, задайте `GW_WEBUI_PORT` при запуске. При повторном запуске существующий `~/hardpro/models/profiles.json` сохраняется. Пример ниже использует адрес из диапазона документации. Замените его адресом сервера в своей сети.

```bash
cd hardpro-hub
LAN_IP=192.0.2.10 DOMAIN=corner.example.invalid bash install.sh
systemctl --user is-active hardpro-hub hardpro-agent hardpro-gateway
```

Доска и агент требуют HTTP Basic. Пароль находится в локальном `~/hardpro/HUB-CREDENTIALS.txt`. Сам шлюз по умолчанию обслуживает HTTP. Для работы с реальными данными используйте доверенный HTTPS-вход или SSH и ограничьте доступ сетью. Агент исполняет команды с правами пользователя службы.

## Модели, замеры и диагностика

```bash
python3 ~/hardpro/bin/hp-model.py list
python3 ~/hardpro/bin/hp-model.py check
curl --fail http://127.0.0.1:9090/v1/models
```

Команды `hp-model.py` запускайте интерпретатором окружения агента при отсутствии его зависимостей в системном Python. Внешние профили проверяются по API. Локальные профили можно запускать и переключать через доску. При включённом `policy.evict` переключение может остановить профиль на том же GPU или порту.

Шаблон `models/profiles.json` и рабочий сервер могут отличаться по контексту, ролям и способу запуска менеджера. В шаблоне менеджер — внешний vLLM, а 27B начинается с 16 384 токенов без MTP. Профиль эксперимента с 65 536 токенами описан в [инструкции по замерам](../systemd/tuning-27b/README.md).

Для диагностики смотрите `~/hardpro/logs/model-*.log` и журнал `hardpro-models.service`. Статус `active (exited)` у загрузчика означает завершение команды автозапуска. Готовность каждой модели проверяется отдельно по её HTTP API.

## Перенос рабочего контекста Codex

`migrate/codex-export.ps1` собирает выбранные файлы на рабочей машине. `migrate/codex-import.py` раскладывает их на сервере и индексирует переписку в SQLite для `bin/hp-search.py`. Перед переносом проверьте, какие проекты и настройки попадут в архив. Сам архив и индекс хранятся локально.
