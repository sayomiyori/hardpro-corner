## Что подтвердили предыдущими тестами

- Менеджер при сбое источника отвечал по снимку с датой. После контрольной перезагрузки сервер отвечал через 30–40 секунд. [Резервный режим 1С](docs/manager-link-recovery.md)
- На 27B выбрали MTP `n=3` по сравнению с обычным декодом, отдельно проверили потоковую выдачу, tool calls и длинный вход. [Отчёт о замерах](docs/llm-speed-27b.md)
- Для поиска инструкций проверили BM25, MiniLM и гибридное ранжирование. Подключение этого пилота к двум чатам требует отдельной приёмки. [Гибридный поиск](docs/knowledge-retrieval-pilot.md)
- Работоспособность OData подтверждается тестом с подставной 1С. У COM-моста свой набор инструментов. Проведение документов и восстановление всей цепочки после отключения питания требуют отдельной эксплуатационной проверки. [MCP для 1С](onec-mcp/README.md) · [Канал менеджера](docs/manager-link-recovery.md)
