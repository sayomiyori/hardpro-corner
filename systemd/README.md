# Пользовательские службы HARD-PRO Corner

Конфигурации Ubuntu для автозапуска модели, восстановления канала к читателю 1С и повторения замеров 27B. Службы разворачиваются в `~/.config/systemd/user/`. `linger` позволяет запускать их при старте машины до входа пользователя.

[К репозиторию](../README.md) · [Текущий статус](../STATUS.md) · [Сборка Ubuntu](../docs/server-setup.md)

## Какие службы есть

| Служба | Роль | Типовой адрес |
| --- | --- | --- |
| `hardpro-vllm` | Менеджерская модель Qwen3-14B-AWQ, отдельная RTX 3090 | loopback `8000` |
| `hardpro-models` | Одноразовый запуск профилей реестра с `autostart: true` | Порт задаётся в каждом профиле, опыт с 27B использует `8084` |
| `hardpro-coding` | Трёхмодельный роутер llama.cpp. Сохранённая конфигурация от 21 ноября | loopback `8081` |
| `hardpro-media-vision` | Анализ изображений и видео | loopback `8083` |
| `hardpro-openwebui` · `hardpro-gateway` | Веб-чат и LAN-шлюз | loopback `8765` и LAN `8775` на проверенном стенде |
| `hardpro-catalog` · `hardpro-onec-link` · `hardpro-link-guard.timer` | Каталог, SSH-канал и проверка читателя | По настройкам площадки |
| `hardpro-flowise` | Отдельный сервис обработки потоков | loopback `8768` на проверенном стенде |
| `hardpro-comfyui` | Генерация фото и видео | Ручной запуск при доступной VRAM |

Для 14B и 27B используйте отдельные GPU. Возьмите UUID командой `nvidia-smi -L` и подставьте его в свой `70-gpu-pin.conf`. Пример `hardpro-vllm.service` ждёт диск моделей, подхватывает два локальных файла окружения и перезапускается после сбоя. Публичные файлы содержат шаблоны, рабочие зависимости и настройки модели задаются на сервере.

## Применение конфигурации

Подготовьте unit-файлы и файлы окружения для выбранных сервисов. `install-autostart.sh` рассчитан на уже установленный стек. Он применяет закрепление GPU, включает дополнительные службы и перезапускает vLLM. Перед выполнением замените UUID в своей копии drop-in. Установщик из репозитория рассчитан на пользователя службы `hp_local_llm`. При другом имени адаптируйте проверку в скрипте.

```bash
bash systemd/install-autostart.sh
systemctl --user list-units 'hardpro-*' --no-pager
```

Настройки роутера и ffmpeg описаны в [статье о чате и медиа](../docs/chat-model-stack.md). Применяйте конфигурацию роутера на стенде с подходящим размещением моделей. На проверенном сервере `hardpro-coding` был выключен, а медиа обслуживался отдельным процессом.

## Диагностика

```bash
systemctl --user list-timers 'hardpro-*' --all
journalctl --user -u hardpro-vllm -u hardpro-models -n 50 --no-pager
nvidia-smi --query-compute-apps=pid,process_name,used_memory --format=csv
curl --fail http://127.0.0.1:8000/health
```

`hardpro-models` может оставаться в `active (exited)` после выполнения команды автозапуска. Проверяйте порт нужного профиля и его лог. Для 27B шаги приведены в [руководстве по замерам](tuning-27b/README.md), для SSH-канала — в [инструкции по восстановлению 1С](../docs/manager-link-recovery.md).
