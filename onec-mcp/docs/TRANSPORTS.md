# Транспорты MCP для 1С

[К модулю 1С](../README.md) · [COM-мост](BRIDGE.md)

| Транспорт | Условие | Точка входа | Запрос |
| --- | --- | --- | --- |
| OData | База опубликована и доступна из сети агента | `node src/server.mjs`, `ONEC_URL` | Имена объектов OData и фильтры `$filter` |
| COM через SSH | На Windows доступен `V83.COMConnector` и разрешено исходящее SSH-соединение | `node src/pipe.mjs`, `ONEC_PIPE_SOCK` | Язык запросов 1С для `onec_query` |

`src/pipe.mjs` передаёт MCP по UNIX-сокету на Windows-сторону. В клиентах выбирайте один транспорт для одного подключения. Форматы аргументов у одноимённых инструментов различаются. Режим и права OData задаются переменными окружения и пользователем 1С, у COM — локальным `config.json` и правами пользователя базы.
